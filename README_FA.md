# حسابداری من — پروژه اولیه اندروید
این پروژه یک نمونه اولیه آفلاین است که با WebView و حافظه محلی مرورگر (localStorage) کار می‌کند.
## ساخت APK
1. پوشه را در Android Studio باز کنید.
2. اجازه دهید Gradle همگام‌سازی شود (برای دریافت Android Gradle Plugin و SDK ممکن است اینترنت لازم باشد).
3. از منوی Build گزینه Build APK(s) را انتخاب کنید.
4. فایل خروجی معمولاً در `app/build/outputs/apk/debug/app-debug.apk` قرار می‌گیرد.
## نکات مهم
- ۱۸ معامله ثبت‌شده از برگه «معاملات» به‌صورت اولیه در برنامه قرار گرفته‌اند.
- این نسخه برای آزمایش رابط، افزودن معاملات و پشتیبان JSON است؛ هنوز نسخه حسابداری نهایی نیست.
- مانده نقدی نمایش‌داده‌شده جمع ساده ستون نقد است و باید پیش از استفاده واقعی با منطق رسید/پرداخت و فرمول‌های کل workbook تطبیق شود.
- اطلاعات برگه‌های «کهاته» و «گودام» هنوز به مدل عملیاتی مستقل تبدیل نشده‌اند؛ مرحله بعدی پیاده‌سازی دفتر حساب و گردش موجودی است.
- قبل از استفاده واقعی از اطلاعات، از فایل اکسل اصلی یک کپی نگهداری کنید.

## ساخت APK بدون Android Studio (با GitHub Actions)
1. محتوای این پوشه را در یک مخزن GitHub با نام دلخواه بارگذاری کنید.
2. در مخزن، بخش **Actions** را باز کنید و در صورت درخواست، گزینه فعال‌سازی Actions را بزنید.
3. گردش‌کار **Build Hisabati APK** را انتخاب کنید و روی **Run workflow** بزنید؛ یا پس از بارگذاری روی شاخه `main`، خودکار اجرا می‌شود.
4. پس از پایان موفق، وارد اجرای انجام‌شده شوید و از بخش **Artifacts** فایل `Hisabati-debug-apk` را دانلود کنید.
5. فایل ZIP دانلودشده را در موبایل باز کنید؛ فایل `app-debug.apk` داخل آن است.

توجه: این نسخه فعلاً نمونه اولیه است و همه امکانات حسابداری/مهاجرت کامل دفترها هنوز پیاده‌سازی نشده است. برای حساب‌وکتاب واقعی، قبل از استفاده باید تکمیل و با داده‌های شما آزمایش شود.
